Observação: as marcações de “liberada” ficam salvas apenas neste navegador usando armazenamento local. Use a data inicial para ignorar séries antigas já ensaiadas/liberadas; BL e BM são separados automaticamente pela descrição do tipo de dormente. A aba Dash board usa filtros próprios, pré-preenchidos com a última semana disponível na planilha, para acompanhar produção semanal por projeto. A aba Refugos / Reprovas usa os registros do bloco de reprovados da planilha e agrupa os motivos automaticamente. Para um controle oficial multiusuário, o ideal é manter a planilha como base mestre e publicar uma versão atualizada no GitHub Pages.
