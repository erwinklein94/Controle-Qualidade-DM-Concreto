Como usar no GitHub Pages

  • Crie um repositório no GitHub.
  • Salve este arquivo como index.html.
  • Envie o arquivo para o repositório.
  • Ative o GitHub Pages em Settings → Pages.
  • Abra o link publicado e importe o CSV.
